# ML-ядро

## Постановка

Прогнозная точка — пара `(ТС, T)`. Целевая остановка — первая по плану остановка
ТС с плановым временем в окне `(T+10 мин, T+15 мин]`; таргет — `факт − план`, с.
Метрика — MAE. В признаки попадают только данные с временем `<= T`.

## Что выяснено о данных

* Все выборки — один день 2026-01-06 и одни и те же 13 реальных ТС. train/test/validate
  чередуются блоками по ~30 минут. `test/traffic.csv` и `validate/traffic.csv`
  совпадают побайтно, `validate/schedule_plan.csv` — это `test/schedule.csv` без факта.
* `cur_dev_s` — отклонение **последней остановки с плановым временем `<= T`**
  (совпадение 98%), а не последней фактически пройденной. Примерно в 42% точек
  факт этой остановки наступает позже `T`, то есть подсказка частично «из будущего».
  В онлайне её честный аналог — `est_now` из трекера.
* 26 синтетических ТС — это копии реальных (по 2 на каждое), сдвинутые по времени на
  −34…+33 мин, с шумом отклонения ~±20 с.
* Факт прохождения остановки восстанавливается из GPS с медианной ошибкой 1.3 с:
  это момент максимального сближения, на конечной — въезд, на начальной — выезд.
* Главный честный сигнал — систематическая ошибка расписания на конкретных участках:
  идентификатор целевой остановки (`tgt_stop`) и маршрута — сильные признаки.

## Утечки и как мы их нейтрализовали

| Утечка | Эффект, если использовать | Что сделано |
|---|---|---|
| Факты целевых остановок validate лежат в `train/test schedule.csv` | MAE = 0 поиском по таблице | не используются: в признаках нет фактов расписания, только план и GPS |
| `cur_dev_s` у последующих точек `points.csv` раскрывает таргеты предыдущих | MAE ~38 c | каждая точка обрабатывается независимо, только `<= T` |
| Синтетика — сдвинутые копии реальных ТС, перекрывающие периоды test/validate | «улучшение» с 71 до 54 c на test за счёт запоминания | синтетические точки, чьё время оригинала попадает в ±40 мин от точек test/validate, исключены из обучения |
| Время суток (`hour`) вместе с синтетикой запоминает конкретный день | — | признак не используется |

## Признаки (`transit_core.features`)

* **План:** горизонт, плановые интервалы вокруг цели, тип остановки (начало/конец рейса),
  число плановых остановок до цели.
* **Трекер:** текущее отклонение `est_now`, отклонение и давность последней пройденной
  остановки, нижняя граница опоздания к следующей, тренд и максимум отклонения,
  изменение отклонения на этом же участке в прошлом рейсе.
* **GPS:** давность и доля валидных точек, скорость за 2/5 мин, доля простоя, путь,
  текущая стоянка, в зоне ли остановки, расстояния до следующей и целевой остановки.
* **Категории:** целевая остановка, маршрут.
* **Последовательность:** 20 бинов по 30 с за последние 10 минут (6 каналов) — вход GRU.

## Модели

| Компонент | Назначение |
|---|---|
| CatBoost MAE × 5 сидов, признаки с `cur_dev` | сабмит по validate (режим с подсказкой) |
| CatBoost MAE × 5 сидов, онлайн-признаки | онлайн-прогноз из потока (без подсказки) |
| GRU + MLP (PyTorch) × 5, экспорт в ONNX | вторая половина ансамбля, телеметрия как последовательность |
| CatBoost MultiQuantile (0.1/0.5/0.9) | интервал прогноза; конформная калибровка до покрытия 80% |
| CatBoost MultiClass (early/ontime/late) | вероятности опережения (< −60 c) и опоздания (> 120 c) |

Ансамбль: 0.5 · CatBoost + 0.5 · GRU (ONNX Runtime). Объяснения — SHAP-вклады CatBoost.

## Качество (честная валидация: обучение на train, проверка на labels_test)

| Модель | MAE, с |
|---|---|
| Нулевой прогноз | 103.3 |
| Baseline `cur_dev_s` | 93.4 |
| **Сабмит: CatBoost + GRU (с `cur_dev`)** | **65.6** |
| Сабмит: только CatBoost | 67.8 |
| Онлайн (без подсказки): CatBoost + GRU | 75.8 |
| Онлайн: только GRU | 77.6 |
| Онлайн: только CatBoost | 79.7 |

Интервал q10–q90 после калибровки покрывает 80.5% фактов; точность трёх классов — 67%.
На потоке (replayer, validate-день) онлайн-MAE ≈ 70 c против ≈ 130 c у наивного
прогноза «текущее отклонение сохранится»; прогнозов задним числом — 0.

## Воспроизведение

```bash
cd services/ml

```

`artifacts/models/v-<id>`, горячая замена без остановки сервиса).
