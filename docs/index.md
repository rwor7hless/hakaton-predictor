# Предиктор задержек городского транспорта

Система раннего предупреждения об отклонениях от графика: принимает поток
телематики NDTP, накладывает его на нитку графика, за **10–15 минут** до
события прогнозирует задержку на остановке, объясняет причину и показывает
алерты на диспетчерском дашборде.
